01 · PowerShell 열기

1. 실행 창Windows에서 Win + R
2. 프로그램 입력powershell 입력 후 Enter
3. 명령 프롬프트 확인PS C:\Users\... 표시 확인
4. 첫 명령 실행Get-Date 입력

일반적인 첫 실습과 npm 기반 설치에는 관리자 권한을 기본으로 요구하지 않습니다.

“우리 병원의 CRM을 분석하고 경영 개선안을 만들어 줘.”

① 목표 접수원장 요청

핵심: AI 여러 개를 연결했다고 자동으로 오케스트레이션이 되는 것은 아닙니다. 작업 순서, 의존성, 실패 시 재시도와 결과 검증까지 관리해야 합니다.

06 · Codex CLI 설치 실습

Node.js와 npm이 준비되어 있는지 먼저 확인합니다.

node --version
npm --version

두 명령어가 정상 작동하면 다음 명령어를 실행합니다.

npm install -g @openai/codex
codex --version
codex

실제 설치에는 인터넷 연결과 적절한 로그인/인증이 필요할 수 있습니다. PowerShell 실행 정책 또는 PATH 문제로 명령이 실행되지 않을 경우 오류 메시지를 확인하고 환경에 맞게 해결하세요. 임의로 보안 설정을 낮추지 마세요.
