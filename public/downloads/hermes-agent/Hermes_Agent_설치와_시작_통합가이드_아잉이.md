# Hermes Agent 설치와 시작 통합 가이드

대상: Windows 10/11 사용자  
목표: 설치 → 모델 연결 → 첫 대화 → 말투와 기억 설정  
이 문서는 강의 중 PowerShell 명령어를 복사해 붙여넣기 쉽게 구성했습니다.

> 텔레그램 연결은 별도 문서인 `Telegram_Hermes_연결_간단가이드.md`를 참고하세요. 이 문서에서는 Hermes의 설치와 시작만 다룹니다.

---

## 0. 시작 전 준비

- Windows 노트북과 충전기, 인터넷 연결
- 사용 가능한 ChatGPT/Codex 계정 또는 다른 모델 제공자 계정
- 비밀번호와 인증 코드를 직접 입력할 수 있는 브라우저
- 회사·기관 소유 PC라면 소프트웨어 설치 권한과 보안 정책 확인

**비용 주의:** Hermes 설치와 AI 모델 이용은 별개입니다. ChatGPT 요금제에서 Codex 사용이 가능한지, 이용 한도가 얼마인지 미리 확인하세요. OpenAI API, 다른 제공자의 API, Nous Portal 등의 이용 조건과 비용은 각각 다르며 별도 과금될 수 있습니다. 결제 화면이 나오면 본인이 확인하기 전에는 결제하지 마세요.

**보안 주의:** 아래 설치 명령은 인터넷에서 스크립트를 받아 이 PC에서 실행합니다. 주소가 공식 문서와 일치하는지 확인하고 실행하세요. 보안 프로그램이 차단하거나 기관 정책과 충돌하면 우회하지 말고 관리자에게 문의하세요.

---

## 1. PowerShell에서 설치

1. Windows 시작 메뉴에서 `PowerShell`을 검색해 엽니다.
2. 아래 한 줄을 복사해 붙여넣고 Enter를 누릅니다.

```powershell
iex (irm https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.ps1)
```

설치 중 필요한 구성요소를 내려받을 수 있습니다. 설치 화면과 소요 시간은 컴퓨터 및 버전에 따라 달라질 수 있습니다. 오류가 나타나면 메시지를 읽고 강사에게 보여주세요. 설치가 끝나면 안내되는 초기 설정을 진행하거나 아래 모델 설정 단계로 이동합니다.

---

## 2. 새 터미널에서 설치 확인

설치 후 PowerShell 창을 닫고 **새 PowerShell 창**을 엽니다. 설치 시 변경된 PATH가 새 창에 반영될 수 있기 때문입니다.

```powershell
hermes --version
```

버전이 표시되면 Hermes 명령이 인식된 것입니다. 추가 점검은 다음과 같습니다.

```powershell
hermes doctor
```

`doctor`가 경고를 표시하면 항목을 확인하세요. 경고가 전혀 없다는 뜻은 아니며 모델 연결이나 실제 대화 성공까지 보장하지 않습니다.

---

## 3. 모델과 계정 연결

PowerShell에 입력합니다.

```powershell
hermes model
```

1. 제공자 목록에서 **OpenAI Codex**를 선택합니다. 일반적인 `OpenAI API` 키 방식과는 다른 선택지입니다.
2. 화면에 나오는 안내에 따라 브라우저에서 본인 계정으로 로그인하고 인증합니다.
3. 장치 코드 입력 방식이 나오면 **터미널이 실제로 표시하는 공식 주소와 코드**를 사용합니다. 인증 코드와 비밀번호를 다른 사람이나 AI 대화창에 보내지 마세요.
4. 계정에서 사용할 수 있는 모델을 목록에서 선택합니다. 모델 이름과 메뉴 순서는 버전이나 계정에 따라 달라질 수 있습니다.

설치 직후 Quick Setup/Full setup이 나타날 수도 있습니다. 화면 구성은 버전마다 다를 수 있으므로 설명을 읽고 진행하세요. Nous Portal 화면에서 원하지 않는 유료 플랜은 선택하지 마세요. Codex로 연결하려면 설정을 마친 뒤에도 `hermes model`에서 제공자를 선택할 수 있습니다.

전체 설정 마법사가 필요할 때만 다음을 사용합니다.

```powershell
hermes setup
```

터미널 백엔드를 묻고 자신의 PC에서 쓰려면 `Local`을 선택할 수 있습니다. **Local은 에이전트가 내 PC에서 명령을 실행할 수 있는 환경**이므로 작업 범위와 승인 요청을 주의해서 확인하세요.

---

## 4. Hermes 실행과 첫 대화

PowerShell에서 다음을 입력합니다.

```powershell
hermes
```

Hermes 대화 화면이 열리면 다음 문장을 입력해 보세요.

```text
안녕하세요. 앞으로 한국어 존댓말로, 컴퓨터 작업은 한 단계씩 쉽게 설명해 주세요.
```

**성공 확인:** 실제 AI 답변이 화면에 도착해야 모델 연결까지 확인된 것입니다. 명령이 실행되거나 설정값이 저장된 것만으로는 충분하지 않습니다.

Hermes 대화 화면 안에서만 사용하는 명령:

```text
/help
```

```text
/exit
```

`/help`는 도움말, `/exit`는 대화 화면 종료입니다. 설치·설정 명령은 Hermes 대화 화면이 아니라 **PowerShell**에서 입력합니다.

## 5. 비서의 말투와 일하는 방식 정하기

### 방법 A: 먼저 대화로 요청하기

Hermes 대화 화면에 아래 예시를 붙여넣고 본인에게 맞게 바꿉니다.

```text
저를 존댓말로 불러 주세요.
답변은 결론을 먼저 말하고 필요한 설명을 덧붙여 주세요.
컴퓨터 작업은 클릭할 곳과 입력할 내용을 한 단계씩 알려 주세요.
결제, 외부 게시, 파일 삭제나 중요한 설정 변경 전에는 반드시 저에게 확인해 주세요.
모르면 추측하지 말고 확인하거나 불확실하다고 알려 주세요.
```

대화에서 요청한 것과 다음 대화에도 자동 적용되는 설정은 다를 수 있습니다. 중요한 규칙은 아래 SOUL 또는 메모리 저장 여부를 따로 확인하세요.

### 방법 B: SOUL.md에 기본 방식 적기

Hermes를 종료한 뒤 PowerShell에서 실행합니다. 기본 Windows 설치 경로의 예시이며, 별도 프로필이나 `HERMES_HOME`을 쓰면 위치가 다를 수 있습니다.

```powershell
notepad "$env:LOCALAPPDATA\hermes\SOUL.md"
```

기존 파일이 있으면 먼저 내용을 살펴보고 필요한 부분만 수정합니다. 위의 말투·승인 원칙을 자신의 상황에 맞게 적고 저장한 후, Hermes를 다시 시작해 확인하세요. 기존 중요한 내용을 무조건 지우거나 덮어쓰지 마세요.

`SOUL.md`는 기본 정체성과 말투를 정하는 파일이고, `/personality`는 선택 가능한 별도 말투·역할 프리셋을 확인하거나 전환하는 명령입니다. 프리셋은 선택 사항입니다.

Hermes 대화 화면에서 프리셋 목록을 보려면:

```text
/personality
```

## 6. 기억과 스킬 이해하기

- `SOUL.md`: 비서의 기본 정체성·말투·행동 원칙
- 사용자 메모리: 내 이름, 직업, 선호하는 설명 방식처럼 오래 쓸 정보
- 작업 메모리: 반복 작업에 도움이 되는 환경과 작업 원칙
- 스킬: 특정 작업을 반복할 때 참고하는 절차와 검증 방법

Hermes 대화 화면에서 예를 들어 다음처럼 요청해 보세요.

```text
제가 한국어 존댓말과 단계별 설명을 선호한다는 점을 기억해 주세요. 실제로 저장했는지도 알려 주세요.
```

메모리 기능의 설정 상태와 승인 방식에 따라 저장이 다를 수 있습니다. AI가 저장했다고 말하면 실제 저장 여부를 확인하고, 새 세션에서도 질문해 보세요. 메모리에 비밀번호·API 키·봇 토큰·환자정보 등 민감정보를 넣지 마세요.

PowerShell에서 메모리 상태 확인:

```powershell
hermes memory status
```

필요할 때만 메모리 설정 마법사 실행:

```powershell
hermes memory setup
```

## 7. 도구와 권한 확인

Hermes는 설정에 따라 파일, 터미널, 웹 등 도구를 사용할 수 있습니다. 처음에는 모든 것을 열기보다 필요한 범위부터 사용하세요. 환자정보가 있는 폴더나 병원 시스템 연결은 강의 실습에서 제외합니다.

PowerShell에서 도구 설정:

```powershell
hermes tools
```

사용 가능한 도구 목록 확인:

```powershell
hermes tools list
```

도구 설정을 변경한 뒤에는 안내에 따라 새 세션을 시작하거나 Hermes를 다시 실행하고 실제 적용 여부를 확인하세요. 파일 삭제·외부 게시·결제·시스템 설정 변경은 사람이 내용을 확인하고 승인하는 방식으로 진행합니다.

## 8. 다시 사용할 때

PowerShell을 열고 아래 명령을 입력하면 됩니다. 매번 새로 설치할 필요는 없습니다.

```powershell
hermes
```

모델이나 제공자를 바꾸고 싶을 때:

```powershell
hermes model
```

설치·환경을 다시 점검할 때:

```powershell
hermes doctor
```

대화가 길어지면 이전 내용을 요약·압축한다는 메시지가 나올 수 있습니다. 이것만으로 이용 한도를 다 썼다는 뜻은 아닙니다. 중요한 정보는 필요한 경우 별도 문서에 보관하세요.

---

## 9. 막힐 때 빠른 확인

### `hermes` 명령을 찾을 수 없어요

1. 설치가 끝났는지 확인합니다.
2. PowerShell을 닫고 새 창을 열어 `hermes --version`을 다시 실행합니다.
3. 그래도 안 되면 설치 메시지와 PATH 설정을 강사와 확인합니다. 명령을 찾지 못하는 상태에서는 `hermes doctor`도 실행할 수 없습니다.

### 모델을 연결했는데 답변이 안 와요

1. 인터넷 연결과 로그인 완료 여부, 계정의 모델 이용 가능 여부를 확인합니다.
2. Hermes 대화를 종료한 뒤 `hermes doctor`로 점검합니다.
3. 필요하면 `hermes model`을 다시 실행해 제공자와 계정을 확인합니다.
4. 오류 화면을 공유하기 전 인증 코드·토큰 등 민감정보를 가립니다.

### 로그인 코드가 만료됐어요

현재 인증을 취소하고 `hermes model`을 다시 실행해 새 코드를 받습니다. 화면에 표시되는 공식 인증 주소를 사용하세요.

### 설정을 바꿨는데 반영이 안 돼요

Hermes를 종료하고 다시 시작해 확인하세요. 도구나 메모리는 새 세션이 필요할 수 있고, 실제 동작 여부도 별도로 확인해야 합니다.

### 보안 프로그램이나 기관 정책이 차단해요

오류 내용을 확인하고 기관 관리자에게 문의하세요. 무조건 실행 정책을 우회하거나 보안 기능을 끄지 마세요.

## 10. 선택: 웹 대시보드

설치된 Hermes 버전에서 지원한다면 PowerShell에서 아래 명령으로 관리용 대시보드를 열 수 있습니다. 메뉴와 기능은 버전에 따라 다릅니다.

```powershell
hermes dashboard
```

화면이나 명령이 다르면 `hermes --help`와 공식 문서를 확인하세요. 강의의 필수 실습은 아닙니다.
