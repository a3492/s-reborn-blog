# 강연 1 | 데이터 품질 및 검산 체크리스트

**전제:** 모든 데이터 100% 합성, 실제 환자 정보 없음.

## 원본 무결성
- [ ] CRM 방문 데이터 200행(헤더 제외), 방문ID 고유 200개
- [ ] 문의 데이터 96행(헤더 제외), 문의ID 고유 96개
- [ ] 문의 유형 건수: 시술·가격 48, 예약·변경 12, 부작용·회복 8, 기타 28
- [ ] 문의 비율: 50.00%, 12.50%, 8.33%, 29.17% (반올림 합계 100%)
- [ ] 금액은 원화 정수, 음수/공란 여부 확인
- [ ] 방문일과 문의일 날짜 파싱 확인

## 집계 및 결합
- [ ] 시술별 방문 건수 합계 = 200
- [ ] 채널별 방문 건수 합계 = 200
- [ ] 시술별 매출 합계 = 전체 방문 매출
- [ ] 고유 고객 수 ≠ 방문 건수 (고객당 여러 방문 가능)
- [ ] `재방문여부`는 생성 순서 기준. 날짜순 재방문은 별도 산출
- [ ] CRM과 문의 CSV는 공통 연결키 없음: 임의 조인 금지
- [ ] 1:N 또는 N:M 조인 시 행 수·매출 중복 증폭 확인
- [ ] 결측·중복·취소·환불 처리 규칙 기록

## AI 결과 검증
- [ ] 사용 모델·실행일·프롬프트 기록
- [ ] 계산식과 분모/분자 확인
- [ ] 임의 추정·근거 없는 인과관계 제거
- [ ] 표의 수치와 결론 문장 일치
- [ ] 의사결정 전 원본 파일로 재검산
