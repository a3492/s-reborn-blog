## 사용할 파일과 AI

## 복붙 프롬프트 1 — 도구 제작
```text
나는 개원을 준비하는 의사다. 첨부한 파일은 100% 가상 수치다.
파일을 입력받아 시나리오별 판매단가, 건당 변동원가, 월고정비, 예상 월시술건수를 읽고
(1) 건당 공헌이익=판매단가-변동원가
(2) BEP 건수=월고정비/건당 공헌이익을 정수 올림
(3) BEP 매출=BEP 건수×판매단가
(4) 예상 월영업이익=예상 건수×건당 공헌이익-월고정비
를 계산하는 간단한 로컬 경영 계산기를 만들어줘.
공헌이익이 0 이하이면 BEP 산출 불가로 표시하고, 0/음수/빈칸 입력을 검증해줘.
가정·계산식·입력값·출력값을 화면에 명시하고 원본 파일은 변경하지 마.
```

## 복붙 프롬프트 2 — 검증
```text
만든 계산기를 아래 독립 테스트 케이스로 검증해줘.
기준: 단가 200000원, 변동원가 80000원, 고정비 12000000원 → BEP 100건, 매출 20000000원.
단가인하: 단가 180000원, 변동원가 76000원, 고정비 12000000원 → BEP 116건, 매출 20880000원.
각 테스트의 공헌이익, 올림 전 BEP, 정수 BEP, 매출, BEP 시점 이익을 표로 제시하고
기대값과 실제값을 비교해 PASS/FAIL로 표시해줘. 공헌이익이 0인 경우도 테스트해줘.
```

## 독립 수기 검산
- 기준: 200,000−80,000=120,000원/건; 12,000,000÷120,000=100건; 100×200,000=20,000,000원.
- 단가인하: 180,000−76,000=104,000원/건; 12,000,000÷104,000=115.384615…건; **올림 116건**; 116×180,000=20,880,000원.
- 단가인하 115건은 손실 −40,000원, 116건은 이익 +64,000원. 즉 BEP는 첫 비손실 정수 건수.

## 추가 테스트
| 입력 | 기대 결과 |
|---|---|
| 단가 100,000 / 변동원가 100,000 | BEP 산출 불가 |
| 단가 90,000 / 변동원가 100,000 | BEP 산출 불가 |
| 고정비 0 / 공헌이익 양수 | BEP 0건 |
| 단가·변동원가에 음수 입력 | 입력 오류 |
| 필수 항목 빈칸 | 입력 오류 |

## 해석 제한
단순 BEP는 세금, 부가세, 환불, 복합 시술 믹스, 가동률, 장비 감가상각 및 고정비/변동비 분류를 자동 반영하지 않습니다. 실제 병원 적용 전에 회계 기준과 원가 가정을 검증하세요.
