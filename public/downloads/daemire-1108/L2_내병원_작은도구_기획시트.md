# 내 병원의 작은 AI 경영도구 | 1페이지 기획시트

**자료 작성 원칙:** 실습은 가상 데이터로 진행. 실제 환자 개인정보 입력 금지.

## 1. 문제 정의
- 내가 반복하는 경영 판단 한 가지:
- 지금의 판단 방식과 소요 시간:
- 도구가 답해야 하는 질문 한 문장:
- 의사결정 담당자:

## 2. 입력 정의
| 입력 변수 | 단위 | 출처 | 갱신 주기 | 검증 규칙 |
|---|---|---|---|---|
| 판매단가 | 원/건 | [ ] | [ ] | 0 초과 |
| 변동원가 | 원/건 | [ ] | [ ] | 0 이상 |
| 월고정비 | 원/월 | [ ] | [ ] | 0 이상 |
| 예상 건수 | 건/월 | [ ] | [ ] | 0 이상 정수 |

## 3. 출력·공식
- 건당 공헌이익 = 판매단가 − 건당 변동원가
- BEP 건수 = ROUNDUP(고정비/공헌이익, 0), 단 공헌이익 > 0
- BEP 매출 = BEP 건수 × 판매단가
- 예상 월영업이익 = 예상 건수 × 공헌이익 − 월고정비

## 4. 검증과 운영
- 기준 테스트: **100건 / ₩20,000,000**
- 단가인하 테스트: **116건 / ₩20,880,000** (변동원가도 76,000원으로 조정)
