# 상담데이터 가공 연습가이드 — 11/8 대미레 청중용

> **오늘의 핵심:** 직원에게 같은 형식으로 메모하라고 요구하지 않습니다. 직원이 쓰던 말투·도구·순서를 그대로 두고, AI가 맥락을 읽어 정리하게 합니다.
>
> **자료 안내(한 번만 확인):** 이 교재에서 다루는 이름·상담·시술·건강 정보는 모두 교육을 위해 만들어 낸 가상 데이터입니다. 실제 환자정보는 ChatGPT 등에 올리지 마세요.

## 준비하기 — 3분

**[문제의식]** 엑셀에 잘 정리된 표만 보면, 실제 병원에서 카톡·전화·메모를 어떻게 모아야 하는지 놓치기 쉽습니다.

**[목적]** 원래 기록을 수정하지 않고, AI가 읽을 수 있도록 모아서 출처를 남기는 연습을 합니다.

1. 브라우저에서 `https://sreborn.net/tools/consult-archive/`를 엽니다. 사이트가 열리지 않으면 강연자가 제공한 다운로드 파일을 사용합니다.
2. `상담데이터_1차_공개용.zip`과 `상담데이터_2차_공개용.zip`을 각각 내려받아 압축을 풉니다. 탐색기에서 두 폴더를 별도로 유지하세요.
3. ChatGPT에서 **새 대화**를 엽니다. 파일을 올리려면 메시지 입력창 옆 `+` 또는 클립 모양 첨부 버튼을 누릅니다. 버튼 이름은 사용 환경에 따라 다릅니다.
4. 초보자는 **먼저 텍스트 복사·붙여넣기**로 실습합니다. 파일 업로드가 막혀도 같은 내용을 연습할 수 있습니다.

**성공:** ChatGPT 입력창에 원본의 일부 문장을 붙여넣을 수 있고, 원본 파일은 수정되지 않았습니다.

**자주 막히는 점:** ZIP 자체를 대화창에 넣기보다 먼저 압축을 푸세요. 표 편집 프로그램이 없어도 TXT/MD는 메모장으로 열 수 있습니다. 파일 내용이 길면 한 고객씩 작업하세요.

## 실습 1. 김민지 고객의 흩어진 기록 모으기 — 6분

**[문제의식]** 이름은 같아도 기록이 여러 파일에 흩어져 있으면 직원이 앞선 상담을 놓칩니다.

**[목적]** 한 고객의 기록을 원문 그대로 모아 **어떤 경로·시점·작성자에서 왔는지** 남깁니다.

**따라 하기**

1. 2차 폴더에서 `04_검수_메타/B02_원본목록_244건.csv`를 엽니다. `customer` 열에서 `B01-C001`을 찾습니다. 이름은 `04_검수_메타/B02_고객60명_작성자12명_마스터.xlsx`에서 **김민지**로 확인합니다.
2. CSV에서 해당 고객의 일반 원본 경로 4개를 확인합니다. 예: `01_경로별원본/전화상담/B02-E001_B01-C001_W01_XS.txt`, `01_경로별원본/전화상담/B02-E002_B01-C001_W04_XS.txt`, `01_경로별원본/오프라인내원/B02-E003_B01-C001_W07_XS.txt`, `01_경로별원본/베가스CRM/B02-E004_B01-C001_W10_XS.txt`. 차례대로 열어 **텍스트를 그대로** 복사합니다.
3. 1차 폴더의 `B01_manifest.csv`에서도 `B01-C001`을 찾아보세요. 연결된 원본 ID를 확인하고, 예를 들어 `B01_원본_카카오톡채널.md`처럼 경로별 묶음에서 해당 제목을 검색합니다. 1차·2차의 원본은 **별개 기록**입니다.
4. 아래 프롬프트를 ChatGPT에 붙여넣은 뒤, `[여기에 ...]` 자리에 복사한 원문을 차례로 추가합니다.

**그대로 복사할 프롬프트**

```text
당신은 병원 상담 기록 정리 담당자입니다. 직원들의 원문 말투는 고치지 마세요.
다음 자료에서 고객 B01-C001(김민지)에 연결된 기록만 정리합니다.
1) 각 기록을 '출처 파일 / 작성자(있을 때만) / 기록 종류 / 원문에서 확인된 내용 / 미확인'으로 나누세요.
2) 환자가 직접 말한 사실, 직원의 해석, 예약·방문처럼 별도 확인이 필요한 상태를 구분하세요.
3) 이름이 같다는 이유만으로 다른 고객의 기록을 섞지 마세요.
4) 원문에 없는 날짜·연락처·시술 여부를 만들어내지 마세요.
5) 중요한 문장 뒤에는 근거가 된 파일명을 붙여주세요.

[여기에 첫 번째 기록의 파일명과 원문 붙여넣기]
[여기에 두 번째 기록의 파일명과 원문 붙여넣기]
[여기에 추가 기록 붙여넣기]
```

**이렇게 나오면 성공:** `김민지 / 고객키 B01-C001 / 전화·오프라인·CRM 등 여러 기록 / 원본 파일명 4개 이상 / 확인·미확인 분리` 형태가 됩니다. 고객 수가 아니라 **원본 건수**를 세어야 합니다.

**검산:** CSV의 고객키와 실제 TXT 제목·본문을 비교하고, AI가 제시한 파일명 수와 내가 붙여넣은 원본 수가 같은지 확인합니다. 파일에 없는 방문 완료나 결제 완료를 썼다면 삭제를 요청하세요.

**흔한 실수:** 1차의 한 Markdown 묶음을 고객 한 명의 기록으로 착각하기, 이름만으로 중복 제거하기, 서로 다른 문의를 한 번의 예약으로 합치기.

## 실습 2. 서로 다른 직원 메모를 AI가 해석하게 하기 — 5분

**[문제의식]** 상담실장은 결론만, 피부관리사는 느낌을, 데스크는 시간을 적습니다. 같은 틀로 다시 쓰라고 하면 누락과 이중 입력이 생깁니다.

**[목적]** 직원의 기록 스타일은 그대로 유지하고, AI의 **해석 결과만** 공통 항목으로 바꿉니다.

**따라 하기**

1. `04_검수_메타/B02_작성자12명_프로필.md`에서 `W01 김서현(상담실장)`, `W04 최다정(피부관리사)`, `W10 서도현(10년차 데스크)`의 습관을 읽습니다.
2. 1번 실습의 김민지 원본에서 각각 `W01`, `W04`, `W10`의 파일을 열어 세 메모를 붙여넣습니다. 직원별 파일명은 반드시 같이 적습니다.
3. 아래 프롬프트를 전송합니다.

**그대로 복사할 프롬프트**

```text
아래 직원 메모를 동일한 양식으로 다시 작성시키려 하지 말고, 원문은 보존하면서 뜻을 해석해 주세요.
직원별로 다음 4가지를 나누세요.
- 원문 그대로의 핵심 표현(짧게)
- 일반적인 한국어로 해석한 의미
- 이 해석의 확신 정도: 높음 / 보통 / 낮음
- 원문만으로는 확인되지 않는 것
'예약?', '확', '재진?'처럼 뜻이 여러 개인 줄임말은 임의로 확정하지 마세요.
직원의 의견을 고객이 직접 말한 사실로 바꾸지 마세요.
마지막에 직원들을 수정 교육하지 않고 AI 정리에서만 통일할 공통 항목 5개를 제안하세요.

[W01 파일명과 원문]
[W04 파일명과 원문]
[W10 파일명과 원문]
```

**이렇게 나오면 성공:** `원문 표현 → 가능한 뜻 → 근거/확신 → 미확인`이 직원별로 구별됩니다. **원문의 오타와 줄임말은 보존**합니다.

**검산:** 결과의 ‘고객 직접 발언’이 실제 고객 문장인지 1줄씩 되돌아가 확인하세요. 뜻을 모르는 약어를 그럴듯하게 확정했다면 실패입니다.

**흔한 실수:** AI에게 “메모를 깔끔하게 고쳐 써”라고만 하기, 원문을 삭제하기, 직원 해석을 의료진의 확정 진단처럼 표기하기.

## 실습 3. 충돌하는 기록 찾기 — 안전 정보 먼저 — 7분

**[문제의식]** 어떤 메모에는 ‘복약 없음’, 다른 메모에는 ‘약 드시는 듯’이라고 적혀 있을 수 있습니다. AI가 둘 중 하나를 골라 확정하면 위험합니다.

**[목적]** 알레르기·현재 복약·임신/수유·부작용·기저질환을 **가장 먼저** 점검하고, 서로 다른 주장을 증거와 함께 표시합니다.

**따라 하기**

1. 2차 원본 목록에서 `B01-C009`를 검색해 네 원본을 찾아 엽니다. 고객명은 마스터에서 **강현우**로 확인합니다.
2. `02_장시간상담_개별/B02-L02_부작용걱정재진_B01-C009.md`도 엽니다. 처음에는 도입부와 건강 확인 관련 구간만 복사합니다.
3. 아래 프롬프트로 **확인된 사실과 주장·추정**을 분리하게 합니다.

**그대로 복사할 프롬프트**

```text
다음 상담 기록들 사이에서 정보의 충돌·누락을 찾아주세요.
가장 먼저 ① 알레르기 ② 현재 복약 ③ 임신/수유 ④ 이전 부작용 ⑤ 기저질환을 확인하세요.
각 항목마다 '원문 A의 주장 / 원문 B의 주장 / 출처 파일명 / 충돌 여부 / 현재 판정 / 반드시 사람이 확인할 질문'을 적으세요.
확정 증거가 없으면 '미확인' 또는 '기록 간 불일치'로 두세요.
'기록 없음'은 '해당 없음'이 아닙니다. 직원 추측을 환자 진술이나 확정 사실로 바꾸지 마세요.
안전상 충돌이 있으면 시술 가능 여부에 대한 판단을 하지 말고 담당 의료진 확인이 필요하다고 적으세요.

[여기에 B01-C009 원본 파일명과 원문 4개]
[여기에 장시간 상담 중 확인할 구간과 파일명]
```

**이렇게 나오면 성공:** 항목별로 `확인됨 / 미확인 / 서로 다름`이 보이며, **충돌을 임의 해결하지 않습니다**. 실제 기록에 해당 충돌이 없다면 ‘충돌 없음, 정보 누락 여부 별도 표시’가 정상 결과입니다.

**검산:** 각 ‘충돌’ 문장이 실제로 **둘 이상의 출처**에서 확인되는지 되돌아가 확인하세요.

**흔한 실수:** 공백을 ‘없음’으로 자동 변환하기, 과거 복약과 현재 복약을 혼동하기, 본인과 보호자의 발언을 같은 사람의 말로 합치기.

## 실습 4. 고객 카드 한 장 만들기 — 6분

**[문제의식]** 긴 원문을 모두 다시 읽어야 한다면 AI 정리의 이점이 작습니다. 반대로 너무 짧게 요약하면 안전 정보가 사라집니다.

**[목적]** 고객을 처음 보는 직원도 **확인된 사실·미결정 사항·다음 행동**을 한 화면에서 보게 합니다.

**따라 하기**

1. 1~3번 결과 중 김민지(`B01-C001`) 자료를 사용합니다.
2. `04_검수_메타/B02_고객60명_작성자12명_마스터.xlsx`에서 김민지 행을 찾아 관심 시술과 기존 기록을 참고합니다. **마스터의 미확인 항목도 그대로 유지**합니다.
3. 아래 프롬프트를 붙여넣어 한 장 요약을 만듭니다.

**그대로 복사할 프롬프트**

```text
고객 B01-C001 김민지의 상담 기록을 병원 내부용 '한 장 고객 카드'로 정리해 주세요.
출력 순서는 다음과 같습니다.
1. 고객 키/이름 및 주요 관심 시술
2. 현재까지의 상담 경로와 확인된 상태(문의/예약/방문/시술/결제는 별도)
3. 고객이 직접 말한 고민과 선호
4. 과거 시술 히스토리(일시·시술·만족도가 기록에 있을 때만)
5. 안전 확인: 복약/알레르기/임신·수유/부작용/기저질환(각각 확인됨·미확인·충돌)
6. 해결되지 않은 질문
7. 다음 할 일: 담당자·확인할 질문·시점(모르면 미정)
각 핵심 항목 옆에 출처 파일명을 짧게 적고, 원문에서 근거를 찾을 수 없으면 '미확인'으로 적으세요.
고객을 강제로 예약시키는 문구나 의학적 시술 권고를 만들지 마세요.

[여기에 앞선 실습 결과와 관련 원문]
```

**이렇게 나오면 성공:** 고객 키가 하나이고, 시술 **문의**와 실제 **시행**이 혼동되지 않으며, 안전 항목 5개가 누락되지 않습니다.

**검산:** ① 출처 없는 사실은 없는가 ② 미확인이 ‘없음’으로 바뀌지 않았는가 ③ 고객의 결정과 직원 의견이 구분되었는가 ④ 다음 행동이 원문에 근거하는가를 확인합니다.

**흔한 실수:** 카드가 그럴듯하다는 이유로 검증 없이 CRM 원본을 덮어쓰기, 고객 이름으로만 레코드 병합하기.

## 실습 5. 8,000~10,000자 장시간 상담 요약하기 — 8분

**[문제의식]** 긴 상담에는 같은 질문이 반복되고 중간에 입장이 바뀝니다. 처음 발언만 읽은 AI는 마지막 결론을 놓칠 수 있습니다.

**[목적]** 긴 상담을 구간별로 요약한 다음 **고객의 최종 의사·안전 확인·다음 행동**을 놓치지 않습니다.

**따라 하기**

## 실습 7. 우리 병원에 적용하기 — 7분

**[문제의식]** AI가 실습자료를 잘 정리해도 직원이 매일 입력하던 방식을 바꾸거나 환자 원문을 무분별하게 외부에 올리면 현장 적용에 실패합니다.

**[목적]** 기존 기록 방식은 유지하면서, **수집 → AI 정리 → 사람 검토 → CRM 반영**의 작은 실험을 설계합니다.

**따라 하기**

1. 우리 병원에서 가장 흔한 경로 하나를 고릅니다. 예: 카카오톡 상담, 전화 메모, 베가스CRM 자유필드, 포스트잇 사진 메모.
2. **실제 고객정보 없이**, 직원이 보통 어떤 메모를 남기는지 형식만 적습니다. 직원이 이미 사용하는 도구는 바꾸지 않습니다.
3. 아래 프롬프트를 붙여넣고, 먼저 한 경로·한 직원·일주일만 적용할 실행안을 받습니다.

**그대로 복사할 프롬프트**

```text
우리 병원은 직원마다 메모 형식이 다릅니다. 직원들의 기록 습관을 통일시키거나 새로 이중 입력하게 만들지 않겠습니다.
아래 업무를 기준으로 1주일 소규모 시험안을 만들어 주세요.
입력 경로: [예: 전화 상담 메모]
현재 기록 도구: [예: 베가스CRM 자유필드, 카톡 나에게 보내기]
현재 문제: [예: 다음 연락할 고객이 누락됨]

1) 원본을 그대로 보관하는 방법
2) 환자정보를 외부로 보내지 않고 승인된 환경에서 필요한 항목만 추출하는 방법
3) AI가 정리할 공통 항목 5~8개
4) 미확인/충돌/안전정보를 사람이 검토하는 순서
5) CRM에 반영하기 전 승인 담당자
6) 일주일 동안 측정할 지표(원본 수, 처리 시간, 누락/오탐, 직원 추가 작업)
7) 문제가 있으면 중단하고 기존 방식으로 돌아가는 방법
을 쉬운 말로 작성해 주세요.
```

**이렇게 나오면 성공:** ‘직원 메모 교육’이 아니라 **원본 보존 + AI 정리 보조 + 사람 최종 확인**의 흐름이 나오고, 성과는 처리 시간과 누락률 같은 검증 가능한 지표로 제시됩니다.

**검산:** 같은 원본 5건을 사람이 먼저 정리한 결과와 AI 결과를 비교합니다. 개인정보 처리 근거·권한·계약·보관·삭제가 검토되지 않았다면 실제 자료를 외부 AI로 보내지 않습니다. 의료 안전정보가 불일치하면 임의 처리하지 않고 의료진 확인으로 넘깁니다.

**흔한 실수:** AI가 추천한 자동화 도구부터 설치하기, 승인 없이 실제 상담 원문을 업로드하기, AI 결과를 곧바로 CRM 확정 기록으로 저장하기.
