# PP08-04 | 중복·누락 경고의 신뢰도 확인

이 파일은 학습용 합성 시나리오입니다. 실제 환자·직원·결제 자료가 아닙니다.

## 문제 상황
AI가 데이터 이상을 경고하지만 실제 오류인지 검증되지 않았다.

## 가상 원문
[기록 1] 가상 데이터의 결제 ID X02가 두 행에 반복됐다.
[기록 2] 예약 상태가 비어 있는 행도 두 건이다.
[기록 3] 중복이 정상 분할 기록인지 원본 규칙은 아직 모른다.

## 학습 목표
탐지 결과와 실제 오류 판정을 구분해 검증표를 만든다.

## 검증해야 할 위험
경고 수를 검증된 오류 건수로 자동 확정하지 않는다.

## 완료 기준
원문에 있는 확인된 사실 2개와 미확인 항목 2개를 구분하고, 추가 질문 3개 및 사람의 검토가 필요한 결정을 적습니다.

## 안전
실제 환자의 개인정보·진료정보·상담 기록을 외부 AI에 올리지 마세요. AI 답변이 증거와 다른 경우 원문을 우선합니다.
