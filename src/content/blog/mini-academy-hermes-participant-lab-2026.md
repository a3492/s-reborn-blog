# 11월 8일 참가자 실습 안내

일시: 2026년 11월 8일(일) 14:30~17:30 예정 / BBG 네트웍스, 서울 강남구 논현동.

## 준비물
- 개인 노트북과 충전기, 인터넷 연결.
- ChatGPT, Claude, Gemini, Grok 중 본인이 이용하는 서비스 계정. 유료 구독은 권장 준비물이지만 **서비스 구독과 개발자 API·외부 에이전트 과금은 별도**일 수 있습니다.
- 별도 테스트 폴더. **실제 환자 정보·병원 비밀 자료는 사용하지 않습니다.**

## 현장 실습의 목표
1. Hermes Agent를 공식 설치 경로로 실행한다.
2. 모델을 선택해 테스트 질문에 응답시킨다.
3. 가상 CSV를 읽어 지표를 계산하고 파일로 보고서를 저장한다.
4. 반복 보고서 형식을 스킬 또는 재사용 지침으로 구성한다.
5. 결과를 검증하고 사람이 승인해야 할 행동을 구분한다.

## 실습 데이터 — 가상 CRM 샘플
아래 내용을 텍스트 편집기에 붙여넣고 `demo_crm.csv`로 저장합니다. UTF-8 인코딩을 사용합니다.

```csv
customer_id,first_visit,repeat_visit,procedure,source
F001,2026-08-01,2026-08-19,laser,search
F002,2026-08-03,,rf,referral
F003,2026-08-05,2026-08-21,laser,search
F004,2026-08-07,,injectable,social
F005,2026-09-01,2026-09-18,rf,search
F006,2026-09-03,,laser,referral
F007,2026-09-05,2026-09-30,injectable,social
F008,2026-09-07,,rf,search
F009,2026-10-20,,laser,search
F010,2026-10-25,,rf,referral
```

이 파일은 **교육 목적의 합성 자료**로 실제 병원 통계를 대표하지 않습니다.

## 과제 A — 데이터 검증부터 시작
프롬프트:

> 이 파일은 가상 CRM 자료입니다. 관찰 종료일을 2026-11-02로 고정하세요. 최초 방문 후 30일 내 재방문율을 구하되, 30일 관찰 기간이 아직 완료되지 않은 고객은 계산에서 제외하고 별도 표시하세요. 날짜 형식·중복 ID·누락값·분모·분자를 먼저 점검한 다음 월별 결과를 표로 만들어 주세요. 원본 파일을 바꾸거나 외부로 전송하지 마세요.

**자체 검산 정답**
- 8월: 적격 4명 중 재방문 2명 = **50%**
- 9월: 적격 4명 중 재방문 2명 = **50%**
- 10월: 2명 모두 30일 관찰 미완결 = **재방문율 산정 불가**
- 전체 적격 8명, 재방문 4명 = **50%**
- 사례가 작으므로 통계적 추론·원인 단정은 금지

## 과제 B — 스킬 재사용
> 앞으로 CRM 보고서를 작성할 때 항상 '데이터 정의 → 적격 표본 → 지표 계산 → 검산 → 관찰된 사실 → 원인 가설 → 추가 검증' 순서로 작성하도록 재사용 가능한 절차를 만들어 주세요. 실제 생성된 파일과 적용 범위를 알려 주세요.

스킬 생성이 지원되는 환경에서는 공식 스킬 기능으로 저장하고, 그렇지 않으면 텍스트 지침 파일을 만들어 동일 프롬프트로 반복 적용합니다.

## 과제 C — 에이전트 실행 검증
> 결과 보고서를 `crm-demo-report.md`로 저장하세요. 보고서를 작성한 뒤 파일을 다시 열어 값이 원자료와 일치하는지 점검하세요. 사용자 승인 없이 외부 메시지를 발송하거나 파일을 삭제하지 마세요.

## 막혔을 때의 점검 순서
1. 인증 문제인지, 모델 선택 문제인지, 도구 실행 문제인지 분리
2. 가장 간단한 질문으로 모델 응답부터 재확인
3. 가상 CSV 파일 경로·읽기 권한 확인
4. 분석 결과를 위의 검산 정답과 비교
5. 설치 오류 시 발표자의 검증된 예비 환경으로 시연을 이어가기

## 안전
- API 키·토큰을 발표 화면, 채팅방, GitHub에 붙여 넣지 않습니다.
- 관리 권한·셸 실행·파일 삭제·외부 발송은 기본적으로 자동 승인하지 않습니다.
- 실습 자료에 환자 이름, 전화번호, 생년월일, 진료기록을 넣지 않습니다.
- 도구가 성공적으로 실행되었다는 사실만으로 분석의 정확성을 보장할 수 없습니다.
