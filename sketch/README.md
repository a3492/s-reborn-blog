- 갈 곳은 세 개다. AI 입문(애린이), 글 모음, Doctor AI 아카데미.
- 아래에 오늘 들어온 곳 몇 개만 둔다. 목록이 바뀌면 사이트가 살아 있는 것으로 보인다.
