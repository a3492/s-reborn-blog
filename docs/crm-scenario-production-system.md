# CRM 시나리오 제작 운영 규격 v1
- 원본 40개는 보존한다. 신규 콘텐츠는 `public/downloads/crm-scenarios/Pxx-yy.txt`와 `public/tutorials/crm-scenarios/index.html`에 추가한다.
- 고유 ID는 P01~P05 + 두 자리 일련번호이며 변경하지 않는다. 시나리오의 주제 이동 시 원래 ID를 보존한다.
- 자료는 반드시 합성 데이터. 실환자 식별정보, 실제 CRM 원본, 실제 연락처 금지.
- 모든 실습에 문제·목적·독립 가상 원문·다운로드·복사 프롬프트·예상 결과·원문 검증·실패 대응·다음 행동 포함.
- 사실/추측/미확인 분리, 문의/예약/시행/결제 구분, 의학적 판단 의료진 인계, 환자 동의 존중.
- `scripts/validate-crm-scenarios.mjs`를 CI에서 실행해 중복 ID, 링크, 파일 존재, 필수 교육 블록 검사.
- 신규 시나리오 제작: 1) 페인 포인트와 미해결 질문 등록 2) 중복 검사 3) 가상 원문 제작 4) 분석/검증 프롬프트 5) 정적 QA 6) 리뷰 7) main 반영 및 Pages 배포 확인.
- 운영 원칙: **CI 통과는 실제 브라우저 검증이나 Cloudflare 배포 성공을 의미하지 않는다.** 실제 배포 성공 및 브라우저 실습은 별도 체크.
- 콘텐츠 자동 발행은 환자 정보 유출과 오류 확산 위험이 있어 검증 후 승인 게이트 유지. 향후 생성형 AI는 새 사례 초안을 작성할 수 있지만 자동 승인하지 않는다.
