# CRM AI 실습 라이브러리 — PP01~PP08 분류 확장 결정 기록 (v3)
기록일: 2026-11-08

## 변경 사유
기존 A~H(일부 원형 A~J)로 구분하던 실습을 PP01~PP05 다섯 분야에 지나치게 통합하여 학습자가 문제를 식별하기 어려웠다. 사용자 요청에 따라 최소 8개 독립 페인 포인트 영역을 운영한다. **A~J는 기존 실습의 구형 식별자이기도 하므로 알파벳 수와 문제 분류 수가 엄밀히 동일한 단위는 아니다.** 이 차이를 이유로 기존 분류 축소를 유지하지 않으며, 학습자가 인식하는 해결 문제를 기준으로 PP 범주를 확장한다.

## 분류 규칙(재발 방지)
1. 문제 원인과 목표가 다른 교육 사례는 기존 5개를 강제로 공유하지 않는다. ‘누가/어떤 업무에서/어떤 실패를/무엇으로 검증할지’에 따라 한 대표 PP를 선택한다.
2. 여러 PP가 연관되면 *대표 분류 하나 + 관련 태그 여러 개*를 적용한다. 현재 페이지의 단일 필터는 대표 분류만 사용한다.
3. 기존 70개 PPxx-yy 시나리오 ID, A~J / Pxx-yy 호환 해시, 가상 파일 URL은 변경하지 않는다. 신규 파일은 PPxx-yy.txt로 만든다.
4. 신규 PP09 이상은 문제 범위가 기존 PP와 실질적으로 다르며 대표 사례가 3개 이상 준비되었을 때 추가하는 것을 기본 원칙으로 한다. **코드 숫자만 채우는 빈 분류를 만들지 않는다.**
5. 제목은 'CRM AI 실습 라이브러리'로 유지하고, 실제 시나리오 수는 코드에서 동적으로 계산한다. ‘70개’라는 고정 수치는 제목에 사용하지 않는다.
6. 의료 결정은 의료진, 개인정보 활용 및 실제 자동 전송은 승인 담당자가 확인한다. 실제 환자 정보는 가상 학습 사이트에 업로드하지 않는다.
