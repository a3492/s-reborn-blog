- 단점: 8칸이라 5~7칸 기준을 넘는다. 「가이드」가 116편으로 비대하다. 같은 주제(예: RAG)가 6칸에 흩어진다. 방문자는 형식보다 주제로 찾는다.

### 권고: A안 (주제 + 패싯)

포털 관행을 근거로 든다.

1. **위키백과의 분류는 주제(그 대상을 정의하는 특성)를 기준으로 한다.** 「목록」「토막글」 같은 형식·관리용 분류는 주제 분류와 섞지 않고 따로 둔다. 포털과 하단 내비게이션 상자도 주제 단위로 묶는다. → AI LAB 7칸 = 주제, 형식은 별도 필터.
2. **네이버 지식백과는 주제 분류가 뼈대**이고, 용어사전·인물 같은 유형은 출처나 컬렉션으로 따로 걸러 보는 축이다. **네이버 블로그 주제 분류도 큰 묶음 → 세부 주제의 두 단계**다. → 2단계, 주제 우선, 유형은 교차 필터.
3. **한 글 = 한 주제(주 분류)**로 브레드크럼이 늘 하나로 정해진다. 위치 표시를 「폴더 주소」처럼 쓰려면 이 조건이 꼭 필요하다(11/20 원장 요청). B안·C안이나 다중 분류는 같은 글에 경로가 여러 개 생긴다.
4. 「다시 오고 싶고 공유하고 싶은」 포털이 되려면 주제마다 **실제 색인되는 정적 페이지**(제목·설명·대표 글·관련 강의)가 필요하다. A안은 주제 7개 = 페이지 7장으로 바로 대응된다.

### 3-4. URL 전략

1. **글 URL은 하나도 바꾸지 않는다.** `/blog/<폴더>/<slug>/`를 유지하므로 의료 AI 강의도 `/blog/doctor-ai/<slug>/`에 남고, 리다이렉트가 필요 없다. 위치 표시와 목록에서만 AI ACADEMY 아래로 보인다.
2. **새 정적 페이지 8장을 추가한다.**
   - `/blog/topics/<slug>/` 7장: 제목, 설명, `CollectionPage`와 `BreadcrumbList` JSON-LD, 대표 글, 형식·수준 필터, 「관련 강의·실습」 상자
   - `/lecture-materials/courses/` 1장: 25편 4부 차례
   - 영문 `/en/blog/topics/<slug>/`는 2차로 미룬다.
3. **옛 분류 주소를 처리한다.** Cloudflare Pages `_redirects`는 쿼리스트링을 조건으로 못 받는다. 그래서 경로형과 쿼리형을 나눈다.
   - 경로형: 지금 `/blog/category/:cat → /blog/?category=:cat` 와일드카드가 있다. 1:1로 대응되는 분류 14개는 **와일드카드보다 위에** 개별 301을 추가한다(예: `/blog/category/orchestration /blog/topics/building/ 301`, `/blog/category/doctor-ai /lecture-materials/courses/ 301`). 둘 이상으로 쪼개진 `aerini`·`faq`·`tips`·`ai`·`ai-agents`·`rag-finetuning`은 지금처럼 쿼리형으로 둔다.
   - `/blog/aerini`, `/blog/aerini/`: 지금 규칙(→ `?category=aerini`)을 유지한다.
   - 쿼리형 `/blog/?category=<옛 id>`, `?group=<옛 id>`: `/blog/` 스크립트에서 계속 처리해 404가 나지 않게 한다. 1:1 분류는 `location.replace('/blog/topics/<새 slug>/')`로 보낸다. 쪼개진 분류는 옛 필터를 그대로 보여 주고 「이 분류는 새 주제로 나뉘었어요」 안내와 새 주제 링크를 단다. 클라이언트 이동이라 301은 아니므로, 새 페이지의 canonical로 보완한다.
   - 레거시 정적 `public/category/*.html` 6개와 `/s-reborn-blog/…` 링크 55개는 별도 과제다(정적 파일이 리다이렉트보다 먼저 나가는지 미리보기에서 확인할 것).
4. 바꾸지 않는 것: `/lecture-materials/`와 그 해시·하위 주소, `/tutorials/*`, `/tools/*`, `/lectures/*`, `/downloads/*`, `/lab/`, `/academy*` 규칙(→ `/tools/`), `/asls`, `/daemire1108`.
