Baseline dc72e914c9cb4d2903ee0548fab4c9311fd727ec. A public archive and JSON feed use a single explicitly publishable manifest. Strict fields, public source allowlist, rejection of private locators and unapproved states. No internal identifiers, private material or draft bodies belong in this repository. Technical validation is not a guarantee of factual correctness or detection of all sensitive passages; editorial review remains mandatory.
News: distinguish announcement, release, availability, and event/publication dates. Research: distinguish protocol and completed results; independently review evidence before results. Education: link reading, practice, completion criteria. Keep stable IDs, version history and source check dates.
Release: run taxonomy, publication gate, theme, CRM, build, browser regressions, actual preview. Merge only verified head/base. Verify canonical deployment SHA and production smoke. No scheduled jobs, settings changes, deletion, or force push. Stop and report failure. Keep existing content unchanged.
