# 강연·자료 메뉴 A안

기준: 글 대수선 계획 v1의 A안(하려는 일). 2026-11-20 승인. 학회·연자·주제를 같은 단계에 두지 않는다. 상단 메뉴는 5개, 깊이는 2단계. 기존 강연 URL은 옮기지 않는다.

## 슬롯

| 메뉴 | 하려는 일 | 주소 |
| --- | --- | --- |
| 강연·자료 홈 | 입구. 아래 세 칸의 지도 | `/lecture-materials/` |
| 자료 | 슬라이드·원본·아카이브를 받는다 | `/lecture-materials/#materials` |
| 실습 | 직접 따라 한다. CRM AI 실습 라이브러리(PP01–PP08)가 여기 있다 | `/lecture-materials/#practice` |
| 발표·기록 | 발표를 다시 본다. 연자와 행사는 이 칸 안의 항목이다 | `/lecture-materials/#talks` |

네 번째 칸을 ‘페인포인트’로 두지 않았다. 페인포인트는 주제라서, 자료·실습·발표와 같은 줄에 두면 기준이 섞인다. 문제 유형으로 실습 안에 둔다.

한 자료가 받는 일과 다시 보는 일을 모두 하면 허브의 두 칸에서 같은 주소로 들어간다. 메뉴 항목 자체는 네 개만 둔다. 강세희·김도위·대미레·KOAT는 하위 메뉴가 아니다.

## 이유

방문자는 “자료를 받을 곳”, “따라 할 곳”, “발표를 다시 볼 곳”을 고른다. 대미레·KOAT(행사), 강세희·김도위(사람), 페인포인트(주제)를 한 줄에 두면 사이트가 무엇으로 나누는지 보이지 않는다. 그 이름은 발표·기록 또는 실습 목록의 항목으로만 남긴다. 자료가 늘어도 슬롯은 바꾸지 않고 항목만 더한다.
